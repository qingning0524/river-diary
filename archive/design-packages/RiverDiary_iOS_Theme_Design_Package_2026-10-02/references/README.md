# 河流日记 · 手机端十版设计草图

日期：2026-10-02。共十个独立设计方向、二十个手机页面。

打开 `index.html` 查看全部方案、放大预览、收藏候选和复制选择；`overview.html` 是十版总览。每个 `variant-XX.html` 为独立的双屏草图，PNG 为对应完整画面。所有 HTML/CSS/SVG 均内置，可离线打开，无外部字体或素材依赖。

## 方案

01. **河流手记**：文学手记 · 章节式日常。
02. **城市漫游**：地图优先 · 地点与故事。
03. **时光胶片**：深色胶片 · 影像生活。
04. **轻盈日常**：清晰平面 · 连续生活流。
05. **生活星图**：安静星图 · 记忆关联。
06. **日子花园**：自然气息 · 生活章节。
07. **生活周刊**：私人周刊 · 每日与每周。
08. **潮汐时钟**：时间节奏 · 一天潮汐。
09. **随身剪贴簿**：纸张收藏 · 照片与短句。
10. **纯净生活**：双栏片段 · 上下文理解。

这些画面是视觉与体验探索，生活记录为示例，不会写入应用数据。餐食热量是示例估算。此次草图重新探索导航、内容层级和 AI 的出现方式，尚未将某一版定为最终产品实现。

记录体验的共同目标：清楚看懂一天；聚合生活片段；照片、地点与活动相互关联；AI 解释自然融入上下文；保留轻松主动记录与纠正的入口。
