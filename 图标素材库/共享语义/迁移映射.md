# SF Symbols → River Glyph 迁移映射

更新:2026-10-19，v2 双端共享。界面只有一套图标，不按平台换风格。iOS 路由 timeline 对应今天，Mac 路由 timeline 对应足迹；完整契约以 routes.json 为准。

以下映射基于当前代码中的实际 `systemName` 用法(`macos/RiverDiaryMac/Sources`、`ios/RiverDiary/RiverDiary`),是**替换建议**,不是已完成的绑定。

## 优先级

- **P0**:导航与主要工作区。先换这里,用户最容易感知统一性。
- **P1**:空态、动作按钮、状态提示。换完 P0 后按页面推进。
- **P2**:方向性与系统控件。可以用新库,但收益低,允许保留 SF Symbols。
- **保留**:系统菜单、窗口控件、Dock/菜单栏模板、以及没有语义对应的符号。

## 建议保留 SF Symbols 的场景

- 系统菜单与右键菜单里的方向箭头;
- 窗口 titlebar、工具栏中的系统动作(全屏、侧栏开关);
- 菜单栏 / Dock 模板;
- 现有代码中大量重复出现、且替换收益很低的 `chevron.right`;
- 没有任何语义对应的 SF Symbol(先讨论语义,不要硬套)。

## 替换顺序

1. **iOS 底部栏**:5 枚;同时把 18pt 调整到 20pt,复核选中胶囊与角标位置。
2. **macOS 侧栏 P0**:13 枚;共享 Original 资源 + Selected 切换,保留现有选中背景。
3. **空态与动作**:每个页面先换 3–5 枚,截图对照,确认 18/20pt 可读。
4. **状态与提示**:成功 / 警告 / 失败 / 信息 / 待确认;同时检查文字与可重试动作。
5. **清理**:旧图集与旧 SF Symbol 引用在截图验收通过后删除;不要一次性全删。

## 验收提示

- 同一页面统一使用本库，共享轮廓与四状态；系统窗口控件可保留 SF Symbols。
- 替换后重新跑深色、最大辅助字号、Reduce Motion 与 VoiceOver 路径。
- 图标换新不等于通过验收:截图、真机与文字信息仍需单独记录。
- 具体规则见 [设计语言](../设计语言.md) 与 [原生资源包说明](../原生资源包/README.md)。
