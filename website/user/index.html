选择由河流日记导出的 JSON 副本。文件只在当前浏览器里解析，不会上传到账号服务器，也不会调用模型。

把记忆副本拖到这里 或 支持 River Memory Mirror v1，也兼容旧日记快照的 entries 结构。上限 25 MB。

DATA BOUNDARY

记忆与账号，各归各处

01

记忆副本默认只在本标签页。导入的 JSON 在浏览器内存和当前标签页的会话存储里解析；关闭标签页后不再保留。

02

账号服务器默认只管理身份。邮箱、设备、会话、权益和反馈会经过账号接口。只有你主动开启云空间后，服务器才会保存端到端加密的密文；它无法读取正文，也不会收到口令。

03

问 River 目前是本机检索。它只引用已导入的原话和日期，不调用模型，不生成未经支持的解释。

04

你可以随时清除。清除本机副本只影响这个标签页；云副本要在「账号与设置 → 云空间」单独删除，不会反向删除原生 App 里的记忆。
