# 河流日记 Mac 赞助演示版 · 试用清单

这份清单给赞助者/种子用户使用，也给维护者做 D11 演示 QA 记录。目标不是“功能全过”，而是**确认不会丢日记、不会误绑账号、不会把个人数据带进安装包**。

## 0. 先记录环境（不要发日记正文）

- macOS 版本：`sw_vers -productVersion`
- 芯片：Apple Silicon / Intel
- 安装包文件名与 SHA-256（DMG 同目录的 `.sha256` 文件）
- 是否首次安装、是否从旧版本升级

## 1. 安装与首次打开

- [ ] 把 `River Diary.app` 拖进 Applications。
- [ ] 首次打开：右键 → 打开 → 再点“打开”。
- [ ] 如果提示“已损坏”/“无法验证开发者”，执行：
      `xattr -dr com.apple.quarantine "/Applications/River Diary.app"`，再打开。
- [ ] 首次启动**不要求登录**，直接看到“今天”页。
- [ ] 「设置 → 账号」显示“当前是本机模式”，有“绑定 River Diary 账号”按钮。

## 2. 本地优先（不绑定账号）

- [ ] 写第一句/第一篇日记，保存后能在“今天”或“足迹”看到。
- [ ] 完全退出 App，再打开，内容仍在。
- [ ] 断网后仍能写、能看、能搜索。
- [ ] 不绑定账号时，不出现账号登录墙；不因未登录关闭资料库。

## 3. 账号绑定与退出（有测试账号时）

- [ ] 在「设置 → 账号」绑定账号；确认后本机资料归当前账号。
- [ ] 退出登录：本机日记仍在，仍能写；不出现空库/资料消失。
- [ ] 换另一个账号登录：应被拒绝，并提示本机资料已属于另一个账号。
- [ ] 绑定失败/断网时：不应留下半绑定状态；重启后仍可用本机资料。

## 4. 备份与恢复

- [ ] 「设置 → 隐私与备份」能显示/复制恢复码；把恢复码保存到本机之外。
- [ ] 导出加密备份，记录“上次加密备份”时间。
- [ ] 在干净用户目录/第二台 Mac 合并备份；用错误恢复码应失败且**不覆盖**现有资料。
- [ ] 恢复后检查：日记、修改、快记、事件数量与备份前一致。

## 5. 隐私与安装包

- [ ] 安装包内没有 `data.json`、`ios-user-data.json` 等个人快照。
- [ ] 未绑定账号时，不向账号服务器发请求（可用代理/防火墙观察）。
- [ ] 反馈问题时**不要**发送日记正文、恢复码、API Key；只发版本、芯片、诊断报告。
- [ ] 如发现安装包包含个人数据，立即停止分发并保留安装包。

## 6. 记录结果

每个问题记录：

- 复现步骤（1/2/3）
- 期望 / 实际
- 是否丢数据（P0）、是否卡住（P1）、是否体验问题（P2）
- 截图（先打码邮箱、日记正文、恢复码）

D11 退出标准：5–8 位 Mac 用户连续 7 天；无 P0 数据丢失；P1 有明确修复/规避；所有安装包通过 `scripts/verify_build_privacy.sh`。
