# macOS 工作区重构

## 方向

原生 SwiftUI、本地优先。日记以用户文字为主，自动素材是可检查的辅助；时间线承载行为回顾，记忆负责找回原文，洞察提供本机统计与显式 AI 请求。

## 范围

1. 统一主窗口、侧栏、导航标题、主题与快捷入口。
2. 日记工作区：直接书写、可选心情、素材侧栏、当日时间线跳转、明确保存状态；应用内切页保留编辑草稿。
3. 记忆工作区：本地搜索、月份/内容过滤、列表与阅读分栏、补记按所属日期归档。
4. 洞察：无 AI 时也可用的范围统计与本机回顾，保留现有六类 AI 分析和来源。
5. 设置：采集、模型、隐私与备份分区。
6. 时间线整理/收藏、备份兼容、跨日正确性继续验证。

## 视觉

纸白 / 石墨背景，低对比细边框，紫灰作为操作强调色。去掉大面积渐变、高光和重复嵌套卡片。阅读正文 14–17 pt；交互文本 12–14 pt。主内容与侧栏独立，窗口缩放时保证最小可读宽度。

## 数据原则

- 保存文字不自动制造心情、精力、专注和产出评分。
- 编辑状态先写入磁盘，成功后发布；失败保留输入。
- 新可选字段兼容旧版加密状态及备份。
- 手动文字与自动采集证据分离，不删除原始记录。

## 验证进展（2026-09-17）

- 78 项 Swift 测试通过，包括 13 项工作区重构测试。
- 保存文字、即时显示与快照重载共用 `JournalWriting` 合并逻辑；本地日期与后续外部同日记录只显示一份。
- 纯文字日记、只有快记的日期不再生成默认评分；图表和本机回顾跳过缺失评分。
- 新字段仍写入既有加密状态，旧版评分编辑保留原计算方式。
- 清空已编辑正文不会重新露出旧 `daily` 文本；源数据保持原样。
- 菜单栏快记保存失败时保留输入。

### 原生界面验收

已在完整 `.app` 中检查：日记编辑区与素材侧栏、浅色和深色阅读、记忆搜索缩小结果、从记忆打开原日期日记、洞察本机统计、设置分区、活动详情与整理弹窗、快捷面板输入日期并按回车跳转。验收未修改用户日记正文，也未触发 AI 外发请求。

历史记录没有实时片段时，日记侧栏保留屏幕汇总；本机回顾优先显示已有心情变化。全局日期控件只在实际使用日期的页面出现。

### 退出保存回归

重启验收发现：`willTerminateNotification` 回调中的异步 Task 可能来不及运行，导致最后活动没有写入当天文件。已改为主线程同步关闭并保存，且保留观察者 token 以便停止记录时正确移除。新增两项测试验证保存必须在通知返回前完成，以及重新开启记录不会累积回调。

最终自动测试：80 项通过。
