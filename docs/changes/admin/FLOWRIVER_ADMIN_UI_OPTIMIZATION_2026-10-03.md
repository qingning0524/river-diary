# FlowRiver 管理后台界面优化验收

日期：2026-10-03。范围：`server/admin-ui` 的界面与操作体验。状态：已发布到 `https://admin.flowriver.xyz`。

## 用户可见变化

- 中文导航配合轻量线条图标，表格和说明文字增大；深色主按钮使用独立文字色，避免浅绿背景搭配白字。
- 手机导航压缩为单行横向滑动，所有页面的表格在自身容器滚动。宽屏用户详情显示在列表右侧，窄屏显示在列表下方并自动定位。
- 查看详情时保留列表及查询条件，详情有独立加载、重试和关闭状态；Escape 关闭后恢复触发按钮的键盘焦点。敏感撤销弹窗打开时主界面不可交互。
- 每页有统一刷新入口，显示 UTC+8 的最近成功读取时间。刷新不清空已有内容，失败后明确提示仍显示旧记录；首次读取失败不会显示“没有记录”。
- 用户状态改变后立即查询，可清除条件。邮箱和用户 ID 继续精确匹配；设备名称和邮件状态筛选仅针对已加载的最近记录，不表示全库搜索。
- 审计记录可按后端游标加载更早记录。切换页面、关闭详情或退出后取消旧请求，避免延迟响应覆盖当前页面或重新填入已清空的数据。
- 创建兑换批次表单默认折叠，展开后宽屏三列、手机单列。生成的兑换码自动滚动定位、分行显示；下载前离开或刷新提示保存，同页数据刷新保留完整码。
- 修复产品权益代码的浏览器表单校验，允许合法的连字符并拒绝空格、大写等非法输入。HTML `pattern` 的字面连字符按 [MDN 的字符转义说明](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/pattern) 处理。

## 验证结果

`npm run build` 通过 Vue/TypeScript 检查和生产打包。最终 HTML、CSS、JS 的 gzip 总体积约 50.6 KB，产物已写入 Go 内置静态资源目录 `server/internal/adminui/generated`。

`go test ./internal/adminui` 通过静态资源包编译检查；该包没有独立的 Go 测试用例。

线上发布后，API 存活、API 就绪、管理页、登录会话入口、新 JS、新 CSS，以及公网 API 就绪检查均返回 HTTP 200。服务进程保持 active，数据库配置、Caddy 配置未更改。服务器保留的回滚副本为 `/opt/flowriver/bin/flowriver-api.previous-admin-ui-20261002T214248Z`；完整码功能仍需管理员登录后手工验收。

本地 Chromium 回归共 67 项通过，使用仅绑定回环地址的示例 API，不访问线上数据：

| 范围 | 覆盖 |
|---|---|
| 响应式布局 | 8 个页面 × 320、390、768、1440px，32 项均无页面横向溢出 |
| 用户查询 | 状态即选即查、清除条件、空结果、追加分页 |
| 详情 | 保留列表、取消慢请求、防止关闭后重开、失败及重试、关闭恢复焦点 |
| 请求与认证 | 切页取消旧响应、刷新失败保留旧记录、首次读取失败、退出丢弃延迟响应、登录二次验证焦点、会话过期 |
| 运维列表 | 设备本地筛选、已撤销筛选、邮件重试/失败筛选、追加审计分页 |
| 兑换码 | 创建表单展开、产品代码验证、完整码显示、未保存离开/刷新保护、数据刷新保留原码、下载后可切页 |
| 外观与控制台 | 深色主按钮文字色、手机展开表单、无未捕获的应用脚本错误 |

故障场景故意产生的 HTTP 503/401 留在控制台记录中，区别于应用脚本错误。此次自动化验收使用本地示例 API；SMTP 送达、生产管理员登录、设备撤销、兑换码生成和数据库真实负载仍需在后台手工验收。
