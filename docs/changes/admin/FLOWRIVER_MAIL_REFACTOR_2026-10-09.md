# 邮件与管理员流程完善 · 2026-10-09

## 本轮交付

- 邮件共享一套内容模型与渲染器，提供支持回复、产品通知、账号通知三种品牌模板；验证码也使用统一品牌体系。
- HTML 邮件使用适配邮箱的表格布局、内联样式、品牌抬头、称呼、段落/列表、参考编号、原始主题、团队签名及官方联系方式；同时生成纯文本版本，无远程图片或跟踪像素。
- 支持发送前预览、快捷正文范例、可选原始内容摘要。界面预览与实际发送使用同一份服务端内容模型。
- SMTP 主题使用规范 UTF-8 MIME 编码，补全 Reply-To / Message-ID；入站回复加入 In-Reply-To / References，保留邮件会话关系。
- 收件箱、用户反馈、写邮件、发送历史分为独立工作区；支持搜索、状态过滤、分页和完整内容详情。历史纯文本邮件保持其原格式，不伪造品牌快照。
- 回复草稿按邮件保存在当前页面内存中，关闭窗口后再次打开可恢复；重新加载提示保护未保存正文，退出或过期清空私人内容。
- 发送意图与审计先持久保存，稳定请求键保证网络重试不会重复发送；SMTP 已接受后忽略 QUIT 断开，无法确认 DATA 接受时记录待确认并禁止自动重发。
- 新迁移 `0010_mail_formatting` 保存实际准备的邮件内容快照，新入站邮件保存原始内容摘要用于重试去重；旧邮件保持不变。
- 入站 MIME 优先选择纯文本正文，跳过附件；HTML 回退剔除脚本/样式且保留段落，修复 UTF-8 截断和字段超限。

## 同时保留的管理员修复

- 防止重置当前管理员验证器造成账号锁死；其他管理员或 SSH 恢复命令继续提供恢复方式。
- 设备搜索查询全部记录，补齐分页；封禁账号的设备状态明确，不显示为可登录。
- 限流检查遵守登录邮箱规范化规则，保留本地部分大小写，统一 IP 格式；数据库错误不再伪报“未限流”。支持密码 IP 与官网反馈 IP 检查，查询可完成步进式验证。
- 统计按 UTC+8 自然日归类，前端支持 7/30/90 天。
- 入站邮件标记已读/删除与审计原子完成。
- 上传支持进度、停止和长传输期限，并在传输前完成重新验证；缺失或大小不符的安装包不能被开放。
- 管理请求超时可恢复，响应格式异常明确提示；自撤销会话返回登录界面。
