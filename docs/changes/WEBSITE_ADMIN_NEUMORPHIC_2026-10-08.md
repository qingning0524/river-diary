# 官网与管理员后台升级 · 2026-10-08

已于北京时间 2026-10-08 20:47 更新 `flowriver.xyz`、`admin.flowriver.xyz` 与同进程账号 API。

## 界面与交互

- 官网与后台统一顶部悬浮胶囊导航、暖灰背景、柔和粉桃光晕、拟态卡片和输入框。
- 官网保留 7 个栏目，后台完整保留 14 个管理模块，通过官网运营/更多管理菜单访问次级模块。
- 支持持久化浅深外观、全屏、键盘导航、手机布局与减少动态效果。
- 官网保留服务器已有公告、下载状态、更新日志和反馈，更新日志默认显示最近 5 条，可展开历史；服务条款和隐私政策沿用相同视觉。

## 修复与功能完善

- 用户精确邮箱/ID 搜索不再匹配无关账号；修复空查询遗漏无邮箱账号、分页遗漏和正常状态包含封禁账号。
- 数据库短暂故障返回 503 并保留管理员 Cookie；真正失效的会话继续返回 401。
- 公告按中文字符计数校验，限制危险链接；后台公告与激活码截止时间按明确 UTC+8 转换，编辑成功提示准确。
- 新增 `0009_admin_session_ids` 迁移，补齐会话管理使用的独立公开 UUID；认证摘要保持私有，`is_you` 只标记当前浏览器会话。新增列兼容旧程序回滚。
- 下载备注与审计在同一事务完成；上传审计失败可重试，同名包不会互相覆盖。
- 安装包通过 `GET/HEAD /downloads/{filename}` 提供，逐次检查开放状态，支持 Range/ETag；未开放、暂停、未知包及目录越界返回 404，不缓存。
- 上传目录改为 `/var/lib/flowriver/downloads`，由服务用户私有读写，文件保持 0600；Caddy 通过 API 获取文件。上传与已发布下载可用 10 分钟单请求期限，其他 API 保留短超时。
- 官网优先显示最新有效公告；下载被暂停、状态失联或元数据无效时撤销入口，提供重试；成功读取空日志时清除旧历史。
- 反馈防重复提交，失败保留草稿；发送期间的新输入不被旧响应清空。弹窗约束键盘焦点并恢复焦点，退出或会话失效清空敏感表单。

macOS 安装包原有暂停状态和 iOS 内测准备状态保持不变。本轮未恢复客户端安装包发布，也未改变 Apple、事务邮件或异机日志配置。
