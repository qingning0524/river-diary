# Mac 原生柔和界面 · 2026-10-15

用户批准 `prototypes/macos-river-os` 的灰蓝色、柔和浮起卡片、侧栏与桌面结构。此前仅接入路由不满足该要求，本轮完成实际原生视觉替换。

## 改动

- `RiverSoftStyle` 统一双向背景阴影、凹陷输入框、双线 River 标记与品牌河流曲线；阴影只作用在背景形状，避免文字发光。
- 海雾蓝默认配色与样品一致；次要正文保留 4.5:1 对比，元数据保留 3:1。深色材料采用相同语义。
- 主窗口改为明确的 216pt 侧栏、66pt 顶栏和内容区域；今天页宽窗口显示当天上下文，详情在相同区域打开，其他工作区可以铺满内容宽度。
- 今天页使用真实摘要、三张指标卡、最近片刻与可展开详情。未知指标保持未知。
- River 页面加入陪伴面板、快捷问题、凹陷输入框与真实资料范围；保留本机检索、配置后的 AI、依据按钮和保存查询。
- 记忆日期档案改为自适应卡片网格，搜索仍覆盖真实文字；全局命令面板同时可以找到具体日记并打开对应日期。
- 待确认以独立卡片展示，确认和纠正沿用 V2 操作，来源继续进入真实 Inspector。额外的回顾、习惯、健康、地点、工作、来源与备份功能都可从“更多工作区”或偏好设置进入。
- 原生日记保存后，右侧文字预览优先展示已保存的本机覆盖内容，草稿优先显示并明确标记。

## 证据

- 全量隔离 Mac 测试：398 通过，0 失败。
- 原生窗口实际检查：浅色、深色、记忆卡片、River 页面、设置；写作保存、重启恢复、搜索结果打开日记；待确认打开原始片段与确认后计数更新。
- 旧 flat-paper 的 seafoam 色阶断言更新为已批准的 soft-material 规则；文字可读性、分隔线、时间线节点几何和所有其他色板守卫保留。
- 新布局导致的设置版心宽度问题已修正为 636pt；时间线空心碎片标记像素测试改为核对当前材质底色，继续验证环与双芯。
