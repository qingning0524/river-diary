# Mac 导航与视觉优化 · 2026-10-16

用户要求全面优化导航结构与美观，延续已认可的灰蓝柔和材质。实际修改 Desktop 主项目中的 SwiftUI 客户端。

## 实施范围

- 统一工作区目录：日常与记忆、回顾与成长、生活洞察、数据管理。每个页面只出现一次，侧栏、前往菜单、⌘K 搜索共享名称、图标、分组和快捷键。
- 单一导航滚动区，独立分组展开状态持久化；快捷键或搜索进入页面时自动展开相应分组。
- 232pt 文本侧栏与 64pt 图标侧栏，⌃⌘S 切换；快记和设置固定底部。
- 有实际行为的工具栏：页面前进后退、当前位置、日期、记一笔、明暗切换。
- 页面历史使用 ⌥⌘[ / ⌥⌘]；原有 ⌘[ / ⌘] 日期快捷键保留，页面历史不改变日期或草稿。
- 统一行高、图标、选中/悬停、待确认数量胶囊、未保存草稿提示与无障碍当前位置。

- 最终隔离 Mac 测试：402 项通过、0 失败（含新增目录完整性、历史边界、分支截断与长会话测试）。
