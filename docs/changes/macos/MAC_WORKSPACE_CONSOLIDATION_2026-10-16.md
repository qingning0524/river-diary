# Mac 工作区合并与体验修复 · 2026-10-16

已完成用户要求的页面价值梳理与原生落地，保留灰蓝柔和材质。主入口从 13 个同级页面收敛为 5 个工作区。

## 页面归属

| 主入口 | 内容 |
|---|---|
| 今天 | 精简日概览、真实指标、最近片刻、当天文字与确认入口 |
| 足迹 | 时间线 / 地点 / 健康 |
| 记忆 | 档案、长期记忆、已保存河流信与收藏 |
| River | 本机记录检索、可追溯依据、可选 AI 整理 |
| 回顾 | 周期回顾 / 待确认 / 习惯 / 进展 |

数据源与只读数据库检查移到原生设置；重复的学习与工作整页入口撤下，真实分类记录保留在时间线和日汇总中。既有深链接与快捷键仍可进入对应分区。旧页面组件未作破坏性文件清理，当前 Shell 不再把它们作为独立主工作区展示。

## 具体修复

- `RiverDestination.workspaceRoot` 统一侧栏选中、分区目录、面包屑与命令入口。共用工作区标题，子页面保留上下文和实际操作。
- 时间线将大块日统计收为可展开摘要，已保存手记改为紧凑预览，编辑器继续使用原有加密草稿和保存流程。
- 确认卡片统一按钮和输入样式，仍能查看源记录、选地点候选、确认和纠正。习惯分区聚焦规则与处理历史，新问题由待确认分区统一承接。
- 健康未同步时提供简明引导和真实心情入口；来源明细按需展开。步数卡正确进入健康分区。
- `DayReviewQueue` 统一宽窄窗局部队列筛选，排除已经进入全局确认中心的目标；空局部队列不再显示误导性“暂无待确认项”。
- ⌘K 的日记搜索从候选查找和最终过滤共享完整文本，修复仅在正文出现的词被再次过滤掉的问题，并统一大小写/变音符匹配。
- 记忆无结果只显示一个空状态；回顾创作打开回顾工作区，避免嵌套一套重复页面。全库搜索不再显示容易被理解为筛选条件的全局日期，新增“写今天”明确写作日期。
- River 输入框固定底部，有答案时收起首次提问建议；滚动阅读后仍能直接继续提问。
- 数据库检查使用携带日期的独立 sheet 请求，首次打开也保持所选历史日。无边框设置窗口通过 AppKit 的 cancelOperation 补全 Esc 退出。

## 根因与验证

| 问题 | 根因 | 验证 |
|---|---|---|
| 页面碎片化与重复标题 | 技术数据视图直接成为同级目的地，各自拥有整页框架 | 五个侧栏入口、两个工作区分区栏；目录与旧路由映射测试 |
