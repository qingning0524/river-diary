用户要求将管理员用户管理页改为拟态页面并完善功能，随后明确将正常用户登录后的个人后台纳入同一轮升级。

## 已实现

管理后台：https://admin.flowriver.xyz/ → 用户。

- 凸起统计卡、内凹查询区、清楚的选中态，适配后台手动明暗模式。
- 数据库全库统计，支持账号状态、邮箱/Apple 身份、密码状态、高级权益、近 7 天活动的组合筛选；所有条件用于服务端查询，分页继续沿用稳定游标。
- 当前筛选标签、选中记录与脱敏 CSV 导出；导出明确限定已加载或已选中记录，不声称是全库导出，转义引号及公式前缀。
- 详情分为概况、登录安全、设备会话、权益、活动（含管理端单会话撤销）；保留密码重置、封禁/解封、强制下线、单会话撤销、设备撤销、权益授予及撤销。
- 操作确认、背景 inert、焦点恢复、键盘页签导航、账户 ID 复制；用户操作捕获账号 ID 和原因，避免重新验证后操作对象变化。
- 修改后刷新列表与统计；服务端无记录的身份、权益、条款均返回空数组，前端同时兼容旧版 null 值。

个人后台：https://user.flowriver.xyz/，现有登录页仍为 https://login.flowriver.xyz/。

- 拟态浅色/深色主题，七栏目：概览、设备与会话、权益与兑换、登录安全、安全活动、反馈与回复、资料与偏好。
- 设备撤销、单次会话撤销、当前设备/会话标识、权益和最近兑换记录、密码双输入及可见切换、邮件验证码重发倒计时。
- 最近账号安全活动；已登录反馈与回复、草稿保留和幂等重试；仅按用户 ID 授权读取反馈，绝不凭公共联系邮箱归入匿名反馈。
- 账号资料 JSON 导出不包含登录令牌、密码或本机日记；浏览器外观偏好、客户端下载链接、账号注销原有邮箱二次验证与最终确认流程保留。
- 修复原用户中心密码保存遗漏 Idempotency-Key 请求头，以及 401 时未强制刷新令牌的问题。刷新请求键随现有会话 cookie 保存，网络重试沿用同一键；临时网络错误不会清掉登录。
- 密码和反馈请求提交时锁定所属表单；失败保留输入，成功才清空；密码从不写入 cookie/localStorage。

## 接口与数据

新增管理员 GET /admin-api/v1/users/summary、GET /admin-api/v1/users/{id}/activity；用户列表接受 password=set|unset、provider=email|apple、premium=active|none、activity=recent|inactive。

新增用户 GET /v1/me/sessions、POST /v1/me/sessions/{id}/revoke、GET /v1/me/activity、GET /v1/me/redemptions、GET/POST /v1/me/feedback。全部使用既有 bearer 认证和当前用户范围，不包含管理员权限。

新增增量迁移 0011_user_feedback_ownership，仅为 feedback_messages 增加可空的 user_id 与索引，旧公开反馈保持匿名；新认证反馈随用户删除而删除。原迁移未修改。
