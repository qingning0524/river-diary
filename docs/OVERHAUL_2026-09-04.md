# 2026-09-04 项目完善记录

## 已落地

### 数据与逻辑

- `build.py` 增加更强的数据校验：日期唯一性、评分范围、指标范围、评分来源、阶段标签。
- 构建产物新增 `summary` 与 `data_quality`，用于总量、均值、健康记录和缺失内容检查。
- 屏幕总时长优先按 App 分钟数聚合，缺失明细时才退回 `screen_h`。
- macOS 应用改为内置定时采集器：读取 iOS 导出的本地数据，清洗评分、睡眠、运动和快记后加密保存。
- 构建期继续合并 macOS 导出的采集快照；不再依赖外部 Hermes 脚本。
- 所有 JSON 写入改为临时文件替换，降低构建中断造成数据损坏的风险。
- 采集器逐条清洗：异常评分、异常睡眠、异常运动记录会被跳过，不会拖垮整次同步。

### Web UI 与功能

- 新增「健康恢复」视图：步数柱状图、睡眠趋势、平均活动能量和当日提示。
- 心情趋势新增近 7 天与前 7 天对比卡，屏幕时间下降会按恢复方向显示为积极变化。
- 「规律分析」新增数据体检与关联线索：待评分、缺概览、缺计划、屏幕/步数/睡眠与心情相关度。
- 新增完整 CSV 与 JSON 导出；原 Markdown 单日导出保留。
- 新增「最新」按钮，翻阅历史日期后可一键回到最新日记。
- 新增帮助弹窗和顶栏帮助入口，说明快捷键、本地评分、导出与隐私边界。
- 命令面板新增健康恢复、数据体检、月度回顾、导出 JSON 与功能指南入口。
- 弹窗锁定逻辑统一纳入帮助弹窗，避免滚动状态被卡住。

### 原生端

- iOS 数据模型支持 `data_quality`，洞察页新增数据体检卡。
- iOS 构建已用 iOS 27 SDK 验证通过。
- macOS 设置提供采集频率、源文件诊断、立即采集、可选快照导出和日记基础快照连接。
- macOS 打包脚本保留；当前环境构建 Release 时调试符号生成受限，但会自动回退打包可执行 App。
