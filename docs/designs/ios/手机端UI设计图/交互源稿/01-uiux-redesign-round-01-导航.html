河流日记 · UI/UX 重设计 — 第 1 轮 导航

五个导航范式，各自回答同一个问题：今天 / 记录 / River / 记忆，这四个区域怎么移动、怎么回来。草图即方案：结构、交互状态、代价都画在图里。2026-10-04
① 红色圆标 = 设计注记，对应卡片下方要点  ·  灰块 = 内容占位，不代表最终视觉风格

A浮岛FLOATING ISLAND

"一岛四站，落点即到"

  • ① 悬浮离底：岛与屏幕边缘脱开，列表从岛下滑过，毛玻璃透出内容。
  • ② 选中 = 实心胶囊：图标+文字一起进胶囊，落点最清晰。
  • ③ 徽标：River 待确认数挂在图标右上。
  • 代价：常驻占用约 80pt 高，沉浸感弱于 C / E。
实现 低适合：要稳、要零学习成本

B河珠中枢ORB HUB

"中央一颗珠，落笔即入河"

  • ① 河珠 = 写日记：最高频动作放在拇指正下方，点按就地隆起成写作页。
  • ② River 徽标：AI 待确认仍是普通席位，不抢戏。
  • ③ 四席 + 一珠：长按河珠 = 心情速记（3 秒存一条）。
  • 代价：五槽更密；键盘弹出时河珠要收编成发送键。
实现 中适合：想让「记录」无处不在

C日期河DATE RIVER

"时间为主轴，流域横滑"

  • ① 日期河：回「哪一天」升为第一操作，河上的刻度即当天记录密度。
  • ② 流域横滑：四区左右滑切换，文字切换器只做锚点。
  • ③ 无底栏：内容高度多出约 13%，签名行移入「关于」。
  • 代价：新范式有学习成本；横滑与列表内滑动要分层处理。
实现 中高适合：把「回溯某天」当核心

D河面水下SURFACE & DEPTH

"今天在河面，其余在水下"

  • ① 水位线拉环：底部常驻一根把手，上拉出抽屉；待确认数挂在把手右端。
  • ② 抽屉三档：半层对照（边看记录边写）、全层沉浸、回落即「今天」。
  • ③ 今天是唯一的家：信息架构最诚实 — 其余三区都是今天的延伸。
  • 代价：到 River / 记忆多一步；抽屉手势需与列表滚动仔细分层。
实现 中适合：极简专注、当下优先

E穹顶PULL DOME

"屏即河面，一拉见全域"

  • ① 水位线：导航缩成一根 2.5pt 的线，线上的四颗珠 = 四区，实心珠是当前。
  • ② 穹顶：水位线上拉停留，四张流域卡扇形张开，松手即跳。
  • ③ 轻扫切换：屏幕左右缘轻扫 = 相邻流域，穹顶只在不清楚时才需要。
  • 代价：学习成本最高；必须给无障碍完整替代路径（按钮入口）。
实现 高适合：极致沉浸 + 独特气质

我的推荐

首选 B（河珠中枢）：它同时解决两件事 — 最高频动作「写日记」获得一个专属的、带品牌形的入口，四区切换仍保持底栏的零学习成本。若你更看重「回溯某一天」，选 C（日期河），它把日记类产品真正的轴（时间）做成了导航本身。
B 与 C 可叠加：河珠做中央入口 + 日期河做顶部时间轴。选定后告诉我字母（或组合），下一轮我把该方案画成完整状态图（选中 / 滚动 / 键盘弹出 / 徽标 / 暗色），并出下一模块「首页 · 今天」的 5 个方案。
