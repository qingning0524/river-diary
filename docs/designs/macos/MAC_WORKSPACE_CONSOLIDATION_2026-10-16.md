# Mac 页面合并与体验重构 · 2026-10-16

用户反馈：部分页面没有独立价值，应删除或合并，并重新设计部分页面。保留已认可的灰蓝柔和美感。

## 已核对的根因

1. Shell 把 13 个技术/数据视图都提升为同级工作区，学习与工作重复展示已有分类时长和时间线，数据源页重复设置中的管理职责。
2. 窄窗 Today 同时展示全局待确认入口和局部空队列，产生“有 1 项 / 暂无待确认项”的表面矛盾；宽窄窗使用两套队列派生逻辑。
3. 今日步数卡使用地点跳转回调，进入地点而非健康。
4. 命令搜索先用完整日记正文匹配，再用缺少正文的关键词再次过滤，正文独有词会被错误丢弃。
5. 每个子视图都拥有整页大标题，合并后需要共享工作区标题与内容级标题，而不能简单叠放旧页面。

## 目标结构

| 主入口 | 内容 | 迁移 |
|---|---|---|
| 今天 | 精简日概览、最近片刻、当天文字与统一确认入口 | 缩短重复展示和装饰占高 |
| 足迹 | 时间线 / 地点 / 健康 | 学习与工作汇总并回时间线和今日分类 |
| 记忆 | 档案、收藏、长期记忆 | 独立搜索与清晰库结构 |
| River | 询问记录与回到证据 | 保留实际检索和依据 |
| 回顾 | 周期回顾 / 待确认 / 习惯 / 进展 | 四个页面合为一个工作区的分区 |
| 设置 | 来源与采集、本地数据库只读检查 | 移除系统页面的主导航入口 |

现有深链接和快捷键保留为对应分区的快捷入口。主导航、命令菜单和选中态共享工作区映射。历史仍保留实际分区，日期与日记草稿不受页面切换影响。

## 实施与验收

先实现工作区映射和共用分区栏，再合并设置入口、统一确认状态，修复搜索与步数跳转。检查真实原生 QA 窗口的标准/窄窗、明暗外观、分区跳转、编辑保存和退出再进入行为；完成隔离测试和 Release 打包到 dist。

不删除用户数据或采集能力；移除的是无独立任务的整页入口与重复展示。

## 已实施的界面与行为修复

- 共用工作区容器、分区选择器和父级选中映射；历史仍记录实际分区。
- 足迹首屏将统计折叠为一行、手记收为紧凑预览，展开后继续使用原有保存与草稿流程。
- 待确认使用同一柔和按钮与凹槽输入样式，保留原始证据、纠正、地点候选和处理反馈。习惯分区保留已确认规则及处理历史，新的待答线索统一前往待确认。
- 健康未同步时显示简明引导与真实心情入口，来源和证据明细按需展开。
- 记忆搜索空结果合为一张说明卡；不再叠放长期记忆、河流信和日期三份空状态。回顾创作从记忆页跳往回顾工作区。
- River 的提问输入固定底部；显示答案时收起首次使用建议。
- “今天”的空局部队列不再制造全局数量矛盾，两个布局使用同一 DayReviewQueue 过滤。过去日期使用“当天/这一天”措辞。
- 数据库通过设置中的只读弹窗打开，并以独立请求携带所选日期，解决首次呈现时读到今天日期的问题。
- 原生无边框设置窗口补全 Esc 的 AppKit 取消操作，关闭后可以再次打开。
