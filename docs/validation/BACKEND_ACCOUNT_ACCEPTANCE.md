## 已执行的本地自动化子集

Go 1.27.1 + PostgreSQL 16.15 临时测试集群，使用每个测试专属的 `test_*` schema，结束自动删除：邮箱规范化/IDN、生产配置 fail-closed、AES-GCM associated-data 和篡改检测、Apple RS256/JWKS 签名及 `aud` 校验、原生 Apple 令牌兑换、App ID 分组复用 Apple 主体、相同 Apple/邮箱地址不自动合并、验证码 outbox 发送与一次消费、注册 consent、相同幂等请求安全重试、会话刷新/令牌重放撤销、服务器限速与账号枚举、邮箱身份显式绑定、异机删除确认/删除状态重试。`go test -race -count=1 ./...`、`go vet ./...`、Linux amd64 交叉构建均通过。测试不读取正式资料库或同步目录。

当时尚未完成的外部/客户端场景属于历史状态：后续已有VPS/DNS/SMTP接收交付记录，但收件箱送达、当前服务、Apple真实启用、异机日志重放/恢复与完整客户端E2E不能由这些记录代替。`go test ./...` 不设置 `TEST_DATABASE_URL` 时会跳过数据库集成用例；正式检查需使用隔离 loopback PostgreSQL 且数据库名包含 `test`。

## 外部故障的用户可见行为

验证码未收到：能在倒计时后重发，旧码失效；不能提示已验证邮箱不存在。邮件/Apple 暂不可用：明确对应方式暂不可用，已绑定设备继续本地使用；只有已绑定的另一身份才可登录同一账号。资料迁移失败：停在可恢复状态，不进入空资料库伪装成功。删除待完成：显示任务进度或失败处理说明，不诱导用户以为离线设备已远程清理。
