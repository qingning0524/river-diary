# River Diary for macOS

情绪日记 macOS 原生应用。核心交互以本机数据为中心，AI 只在用户显式开启时参与分析。

## 直接打开

```text
../../dist/River Diary.app
```

双击运行。重新打包：

```bash
./make_app.sh
```

## 核心体验

- **日记**：打开就是可书写的一页，心情可选；⌘S 保存，应用内切页保留未保存草稿。仅保存文字不会制造评分。
- **时间线**：周日期导航、活动段落、原始依据、快记、整理与收藏；可以回到相同日期的日记。
- **记忆**：一个入口承接三种回看方式：按天浏览档案、查看周期回顾、确认可长期使用的记忆；月度河流信也会在这里按月份保存和重读。
- **询问**：先用本机统一记忆库查找日记、快记、长期记忆和河流信，再按需调用已验证模型生成带证据的回答。
- **设置**：记录与采集、AI 与模型、隐私与备份分区。
- **窗口尺寸**：在“窗口大小”菜单选择 960×640、1280×800 或 1440×900；窄/标准宽度详情使用右侧浮层，宽屏与内容并排。
- **快捷入口**：⌘1–⌘3 切换 Today / Memory / Ask，⌘K 打开命令面板，⌘F 搜索记忆，⇧⌘N 留一句快记。
- 本机自动素材和 AI 文本都通过用户点击追加到草稿，已有文字不会被自动替换。
- 原有情绪河、节律、月度河流信、AI 搜索、随笔、数据查询和备份继续可用。
- 日记与整理结果写入现有 AES-GCM 加密状态；支持浅色和深色模式。

## 页面结构

主窗口是原生 `NavigationSplitView`：日期选择和采集状态在左侧导航，Today、Timeline、Daily Review、Health、Footprints、Work & Learn、Memory、Ask、Progress、Database、Sources 与 Settings 分组呈现。
可选择打开右侧 Inspector 查看 Episode、Memory 与回答依据；窗口窄时 Inspector 作为浮层显示，避免挤窄时间线。

- **Today**：时间线优先的一日首页（含 NOW 当前活动、日期切换、写一句快速入口）。
- **Memory**：包含档案、周期回顾和长期记忆三个视图；回顾不再是独立的顶层入口。长期记忆可以确认或标记为不准确，并展开查看来源片段。
- **Ask**：本地查找会同时读取四类记忆来源；回答会标注基于多少条证据，并可点击查看依据。
- **Settings**：录制 / 模型 / 隐私 / 数据源健康。

无 AI 连接也可以正常使用时间线与本地回忆；日记草稿会加密保存并可在重启后恢复。

## 自动素材源

应用默认读取内置 `data.json` 快照。也可以在「设置」页连接项目数据管道生成的 `data.json`。连接后，本日概览会读取该项目已有的自动记录结果。

iOS 导出的 `river-diary-user-data.json` 由 macOS 定时采集。采集器会清洗本地评分、睡眠、运动和快记，加密保存到本机，再合并进应用数据。

## 定时采集

- 默认每天 22:30 定时采集，可在设置中调整时间；只有模型已验证连接时才会按设置自动触发 AI 每日分析；
- 应用打开期间由系统定时器检查采集时间；
- 源文件内容哈希未变化时不会重复解析；
- 可在「设置 → 自动记录 → 立即采集」手动触发；
- 从 `dist/River Diary.app` 运行时，会自动导出到项目的 `data/ios-user-data.json`；也可在设置里更改或停止导出。

## 本地数据

修改和快记保存在：

```text
~/Library/Application Support/RiverDiaryMac/journal.state
```

该文件使用 AES-GCM 加密，密钥保存在本机应用目录并限制为当前用户可读。旧版本钥匙串密钥只在迁移时读取一次。原始个人数据快照不进入 Git 历史。

兼容 SQLite 库和 V2 事实库使用 SQLCipher；数据库密钥由本机状态密钥派生，启动不要求额外输入密码。完整加密备份同时包含兼容库和 V2 事实库快照。密钥丢失后数据库不可恢复，同一 macOS 账户下运行的进程也可访问密钥；跨设备密钥恢复尚未实现。第三方加密组件许可随应用资源附带，可在“设置 → 隐私与备份”查看。

采集快照单独保存在：

```text
~/Library/Application Support/RiverDiaryMac/Ingestion/health-snapshot.bin
```

活动证据也会同步写入 V2 事实层：

```text
~/Library/Application Support/RiverDiaryMac/Database/V2/river-v2.db
```

实时应用片段和每日采集快照进入 `raw_events`，并生成可重建的 `activities` 与 `episodes` 投影。现有加密活动文件仍作为兼容读取来源，V2 数据不会删除旧数据。

## 开发

```bash
./run.sh
```

`run.sh` 启动 Debug 构建；`make_app.sh` 生成 Release `.app`。

### 发布签名与公证

默认构建使用临时签名，适合本机验证。发布给其他 Mac 时，先在钥匙串中准备 Developer ID Application 证书，再传入签名身份：

```bash
CODESIGN_IDENTITY="Developer ID Application: 你的名称 (TEAMID)" \
RIVER_APP_VERSION="1.0.1" \
./make_app.sh
```

如果已经在 `xcrun notarytool store-credentials` 中保存公证凭据，可以追加 `NOTARY_PROFILE`，脚本会提交并 stapler 公证结果：

```bash
NOTARY_PROFILE="river-notary" ./make_app.sh
```

没有签名证书时不要把临时签名的应用当作正式发布包；它只用于本机运行和功能验收。

## 月度河流信

在「Memory → 回顾」查看本周期统计和当前自然月的河流信；保存过的河流信会在「Memory → 长期记忆」中按月份重读。只需有日记、快记或实时足迹即可生成本机草稿，不要求连续记录 30 天。缺失评分和睡眠不会按零计算；跨月足迹只计入月内部分。

可编辑标题和正文、保存、收藏、筛选收藏、从历史列表重新打开，以及复制或导出 Markdown。保存版本不会随数据更新自动改写。信件与收藏状态写入现有加密 `journal.state`，并纳入加密备份与恢复；Markdown 是供用户主动导出的可读文件。

在「Ask」中可以把常用的关键词和时间范围保存为快捷查询。快捷查询写入加密本地状态，支持一键执行、编辑名称/条件、按最近使用排序和删除。

## 双源足迹策略

河流日记现在同时保留两类信息源：

- 项目管道：每日屏幕总时长、应用明细、浏览足迹、运动信息，作为总量权威来源。
- macOS 实时足迹：基于应用切换事件记录前台应用片段，不做 5 秒轮询，用于时间线、专注块和节奏分析。

融合规则：

1. 应用总时长以项目管道为准，不与实时片段重复相加。
2. 精确时间分布、最长片段和专注时长来自 macOS 实时足迹。
3. 浏览足迹与运动信息只来自项目管道。
4. 两者差异较大时会标记置信度，不会让 UI 或 AI 草稿重复计算。
5. 实时片段按天加密保存，只在应用切换、睡眠、锁屏或退出时写入。
6. 单日统计结果有缓存；多天统计只聚合单日缓存。

## AI 大模型分析

模型连接为可选项。无 API Key 时应用仍可启动，提供本地事实整理和本地检索；需要 AI 生成时，再在「设置」页添加 OpenAI 兼容 API 并主动测试连接。

- 本地分析模式保留；连接模型后，可手动生成 AI 回顾或启用定时 AI 分析；
- API Key 保存在本机加密文件，并限制为当前用户可读；旧版本钥匙串中的 Key 会在使用时迁移，不在启动阶段请求钥匙串密码；
- 启用定时采集且有已验证的模型连接时，每天到设定时间（默认 22:30）后可自动生成当天总结；失败后会在下次定时或应用启动时重试；
- 足迹页的「问足迹」可以使用 AI 分析；
- 洞察页一次综合请求生成每日总结、情绪关联、专注分析、健康恢复、本周规律和行动建议，单卡仍可独立重写；
- 请求前先在本机计算平均评分、足迹总量、专注时长、主要应用及健康覆盖，减少模型猜算；
- 六项结果统一为结论、关键依据、建议、边界结构，并按日期范围留档，可查看依据与对比上周期；
- 请求只携带所选范围的数据；跨天足迹包含完整日期，切换日期时旧请求不会回写到新范围；
- 窗口标题默认不会随分析请求发送，可在隐私页单独开启；
- API 未通过验证时不会发送 AI 请求；自动分析失败会保留错误提示，并在下次启动时重试。

## 生活时间线（macOS）

进入主应用的「时间 → 时间线」。界面参考 [Dayflow Timeline](https://github.com/JerryZLiu/Dayflow)，使用原生 SwiftUI 实现，并连接河流现有日记与加密快记。

- 一周日期带、日历与前后日导航统一切换当天记录；「写这一天」打开相同日期的日记。
- 左侧按时间展示活动、快记和未记录空档；右侧展示活动依据，未选择时显示当天日记、心情及时间分布。
- 活动标题优先使用已采集的窗口标题；没有标题时只显示使用的应用，不推断完成事项。
- 相邻同类片段间隔不超过 2 分钟、合并跨度不超过 45 分钟时归为一段；可以切换到原始片段，按分类或关键词筛选。
- 快记区固定在详情栏下方，写入原有加密日记；写于其他日期的补记单独展示，不伪造当天发生时间。
- 可暂停/开启记录、定位最近一段、复制或导出当天 Markdown；导出包含当天全部片段、已采集的窗口标题及快记，不受搜索筛选影响。
- 7 天与 30 天概览继续提供双源统计、应用排行、趋势和身心关联。
- 实时片段跨日裁剪，重叠片段不会重复计时；锁屏/屏保进程不计入时间线或实时统计，历史源文件保持原样。

此功能使用现有应用切换记录，不新增录屏权限或自动外发 AI 请求。窗口标题是否采集仍由系统页中的原有开关控制。

### 整理与收藏活动片段

点击活动卡片后，在右侧选择「整理这段时间」，可以设置自己的标题、补充感受、收藏；也可通过卡片右键菜单操作。筛选栏的星标只显示收藏片段，搜索会同时匹配自定义标题和补充文字。

整理结果写入现有加密日记，并随完整备份导出和恢复；当天 Markdown 也会包含个人补充与收藏标记。原始窗口标题和应用依据保留。清空标题、补充并取消收藏后，片段恢复自动展示。旧版日记和备份仍可读取。

切换日期时，当前时间线中的未保存快记会按日期暂留；离开时间线或退出应用前仍需点击「留下这句」保存。跨午夜尚未结束的活动现在会分别计入对应日期。
