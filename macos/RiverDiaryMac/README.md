# River Diary for macOS

情绪日记 macOS 原生应用。核心交互以本机数据为中心，AI 只在用户显式开启时参与分析。

## 直接打开

```text
../../dist/River Diary.app
```

双击运行。重新打包：

```bash
./make_app.sh
```

## 核心体验

- 打开即进入「今天」，不是空白编辑器，而是 AI 草稿；
- AI 会根据自动素材生成叙述、标签、分类、评分和置信度；
- 每条草稿都能展开「查看依据」，避免黑盒判断；
- 用户可以：保存草稿、只改一句、今天不记、恢复草稿；
- 手动评分被降级为可选微调，不再要求用户先填表；
- 菜单栏有 🌊 快记入口，可随时保留一句话、链接或想法；
- 快记素材会并入当天 AI 草稿；
- 「河流」显示情绪变化，并尝试解释低谷、恢复和当前状态的原因；
- 「回忆」支持自然语言问题，例如：哪几天很累？本月提到工作了吗？低于40有哪几天？
- 低落或重词会触发温柔保护，AI 不催促完整复盘；
- AI 自动整理可以暂停，暂停时只保留素材，不生成草稿；
- 可以连接项目数据管道生成的 `data.json`，并自动感知文件更新；
- 足迹页提供情绪 × 足迹关联线索，帮助看见屏幕、专注、运动与心情的关系；
- 本地修改使用 AES-GCM 加密，密钥保存在 macOS 钥匙串；
- 支持浅色 / 深色模式、⌘1–⌘5 页面切换、⌘S 保存草稿。

## 页面结构

- **主页**：AI 草稿、证据、身体状态、快记、可选微调；
- **河流**：情绪曲线与原因标注；
- **回忆**：自然语言搜索、洞察、随笔；
- **足迹**：双源摘要、24 小时分布、应用排行、浏览足迹、运动信号、情绪关联；
- **设置**：模型 API、数据采集、基础快照、加密状态、实时足迹、导出、清除数据。

## 自动素材源

应用默认读取内置 `data.json` 快照。也可以在「设置」页连接项目数据管道生成的 `data.json`。连接后，本日概览会读取该项目已有的自动记录结果。

iOS 导出的 `river-diary-user-data.json` 由 macOS 定时采集。采集器会清洗本地评分、睡眠、运动和快记，加密保存到本机，再合并进应用数据。

## 定时采集

- 默认每 30 分钟采集一次，可选 5 分钟到每天；
- 使用 `NSBackgroundActivityScheduler`，应用打开期间由系统安排后台工作；
- 源文件内容哈希未变化时不会重复解析；
- 可在「设置 → 自动记录 → 立即采集」手动触发；
- 从 `dist/River Diary.app` 运行时，会自动导出到项目的 `data/ios-user-data.json`；也可在设置里更改或停止导出。

## 本地数据

修改和快记保存在：

```text
~/Library/Application Support/RiverDiaryMac/journal.state
```

该文件使用 AES-GCM 加密，密钥由钥匙串保护。原始个人数据快照不进入 Git 历史。

采集快照单独保存在：

```text
~/Library/Application Support/RiverDiaryMac/Ingestion/health-snapshot.bin
```

## 开发

```bash
./run.sh
```

`run.sh` 启动 Debug 构建；`make_app.sh` 生成 Release `.app`。

## 双源足迹策略

河流日记现在同时保留两类信息源：

- 项目管道：每日屏幕总时长、应用明细、浏览足迹、运动信息，作为总量权威来源。
- macOS 实时足迹：基于应用切换事件记录前台应用片段，不做 5 秒轮询，用于时间线、专注块和节奏分析。

融合规则：

1. 应用总时长以项目管道为准，不与实时片段重复相加。
2. 精确时间分布、最长片段和专注时长来自 macOS 实时足迹。
3. 浏览足迹与运动信息只来自项目管道。
4. 两者差异较大时会标记置信度，不会让 UI 或 AI 草稿重复计算。
5. 实时片段按天加密保存，只在应用切换、睡眠、锁屏或退出时写入。
6. 单日统计结果有缓存；多天统计只聚合单日缓存。

## AI 大模型分析

在「设置」页可以配置 OpenAI 兼容 API。支持自定义 API 地址、模型名称和 API Key。

- API Key 保存在 macOS 钥匙串；
- 足迹页的「问足迹」可以开启 AI 分析；
- 请求只携带所选范围的足迹摘要；
- 窗口标题默认不会随分析请求发送，可在隐私页单独开启；
- API 失败或未配置时仍可使用本地解读。
