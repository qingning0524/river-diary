- 原生五页接到现有采集、SQLite、用户决定、自动 AnalysisJob/Artifact 和加密复制系统。
- 今日页以自动小结、原始采集数量、观察时段与健康摘要为主；手动补充仅为辅助入口。
- 足迹显示自动事件；待确认沿用真正的地点/事实/习惯澄清，不再把每条日记事项变成确认任务。
- 我的增加自动日记归档、全文搜索与按日依据回看。保留原有补充文字、收藏、同步与备份能力。

- 全局日期与日界更新保留历史查看上下文；AI 调度键包含日期，避免沿用昨天的自动任务去重键。

## 2026-10-15：按原图与交互样本校正

设计依据是桌面项目 `new design ios` 五份 `screen.png` / `code.html` 和 `samples/ios-redesign` 交互样本，不再用旧原生页面结构替代它们。用户后续确定的统一顶部日期、删除工具排、拟态风格与自动记录定位优先。

- 今天：自动小结、四张成对等高的功能卡、原图中的一句诗；保留可选补充。
- 足迹：紧凑地图面板、待确认提示、可排序和筛选的卡片时间线；已有授权下显示关联的本机照片。没有位置或照片数据时不伪造轨迹与影像。
- 待确认：依据和问题直接放在卡片，候选选择、自定义、跳过与确认均在卡片完成；原有依据详情和恢复确认保留。
- River：伴随卡、问题建议、对话气泡、可打开的依据卡、底部输入；重复的原始事件引用按生活片段去重显示。
- 我的：可编辑资料、本机档案统计、四类记忆入口、习惯规则、搜索回顾、系统分享导出文字编年史。项目/人物/习惯为空时显示真实空态。导出当前搜索匹配的日记与记忆，不是 PDF。

## 原始拟态与足迹时间线修正

本轮直接使用 `new design ios` 原始 HTML 的材质值：底色 #EEF2F6；普通卡片同色双向阴影；足迹卡片仅用 #F7FAFE → #E5EBF2 浅渐变。取消 SwiftUI Color.gradient 的自动深色尾端与模拟凹槽的模糊描边，凹槽改为原生 inner shadow。网页交互样本同步使用这些材质值。

足迹按原图顺序组织：地图 → 时间线标题 → 待确认提示 → 连续细轴与生活片段卡片。搜索/分类进入筛选入口；原始来源通过点开片段查看；全天手记/健康默认折叠。当前 AI 片段只替代完全覆盖的原始行，部分覆盖的观察时段保留，过期或尚待设备核对的 AI 结果不替代事实。时间线排序和记录/依据/地图入口保留。

新增 3 项时间线呈现回归测试。在 SDK 27 模拟器测试连接报 DTServiceHubClient failed to bless service hub 后，使用 macOS 临时 Swift 包直接链接生产 RiverFootprintPresentation.swift 与同一 XCTest 文件进行隔离运行，3 项通过。该验证只覆盖 Foundation 呈现合并逻辑，不代表 iOS XCTest 或真机 QA 已通过。原生界面仍通过签名 QA 模拟器截图与实际 AX 操作核对。

原生 QA 实际操作：地图下「生活片段」跳转至时间线；倒序切换为正序；AI 片段打开实际活动详情与原始依据。截图 `trail-timeline.png` 展示滚动后的卡片与连续细轴。Debug 和 Release 均编译通过。

## 页面标题随滚动

顶部 RiverSharedDateHeader 仅保留共用品牌和全局日期。五个主页面的标题、说明与待确认数量分别放入各自 ScrollView 内容顶部，由 RiverScrollingPageHeading 统一样式。页面上滑时标题自然离开视口；切换页面仍显示对应标题。交互样本采用相同结构：品牌日期在全局顶部，页面标题进入 screen-stack 滚动区域。

## 拟态动效

统一轻量触感：按压缩至 97.5% 后用短弹簧回弹；页面以 8pt 位移与 0.32s 淡入出现；底部选中凹槽通过 matchedGeometryEffect 在五个入口间平滑移动；确认卡片在真实保存后淡出并收拢队列；时间线重排与新对话使用短过渡。减弱动态效果时去掉位移、缩放与弹簧，只保留短淡入或立即更新。页面标题仍属于滚动内容，顶部品牌/日期保持共用。

网页交互样本提供同类可体验动效：有限的 Web Animations、跟随选中的导航凹槽、选项反馈、对话进入、确认卡片退出与系统弹窗出现。记录先持久化，再播放退场动画；快速切页或取消动画不会撤销保存。没有循环装饰动画或伪造进度。
